# Plantillas de gobernanza

Toda modificación requiere:
1. **Acta de chat:** fecha, objetivo, fuentes, decisiones tomadas, disensos, archivos producidos, limitaciones.
2. **Registro RD:** decisión con justificación, alcance, estado y vigencia.
3. **Registro RP:** pendiente con responsable e impacto.
4. **CR / Pull Request:** cambios de artefactos, trazabilidad y pruebas.
5. **Manifiesto de fuentes:** nombre, tipo, versión, fecha y SHA-256 cuando el archivo está realmente disponible.

Las plantillas formales se encuentran en esta carpeta. La bitácora no reemplaza los archivos editables.
